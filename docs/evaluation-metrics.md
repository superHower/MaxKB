# 智能体评测指标定义

## 离线回答指标

### 答案正确性

判断答案是否覆盖标准答案中的关键事实，输出 0～1 分、布尔结论和理由。标准答案优先使用人工标注，不能直接把模型生成答案当作真值。

### 引用相关性

判断引用段落是否支持问题和答案。引用相似度只能作为检索信号，不能替代引用内容审查。

### 无答案识别

分别统计：

- 知识库无答案时正确拒答率；
- 知识库有答案时误拒答率；
- 无答案场景总体准确率。

### 忠实度

检查答案中的陈述能否由最终上下文支持，输出支持比例和未支持陈述理由。

### 检索指标

继续保留 `hit_rate`、`context_precision`、`context_recall`、`MRR`、`precision_at_k`，并明确这些指标只代表检索质量。

## 线上业务指标

| 指标 | 建议定义 |
| --- | --- |
| 解决率 | 会话被用户确认解决、无追问且未转人工，或人工抽检判定解决 |
| 一次解决率 | 首次回答后会话结束且判定解决的会话占比 |
| 转人工率 | 进入人工处理流程的会话占比 |
| 引用准确率 | 抽检或自动评估中引用支持答案的会话占比 |
| 无答案率 | 被判定为知识库无答案的有效问题占比 |
| 点赞率/点踩率 | 用户反馈中的正向/负向比例 |
| 成本/次 | Token、模型价格和重试成本合计 |
| 延迟 | 平均、P50、P95、P99 响应耗时 |

所有指标都必须支持按应用、版本、知识库、模型、实验组和时间范围过滤。

## 指标计算注意事项

- 解决率不能只由模型 Judge 决定，应结合反馈、追问、转人工和人工抽检。
- 无标注的样本不计入需要真值的准确率分母。
- 线上指标需同时展示样本量和置信区间或至少展示有效样本数。
- 版本比较必须使用相同样本或明确列出样本变化。
